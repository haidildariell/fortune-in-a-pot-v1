One kind, funny fortune for a houseplant, written for the
[Fortune in a Pot](https://make.fun/competitions/u-golden-heron-44-fortune-in-a-pot-ded981e9)
competition on make.fun.

## The fortune

> Soon you will outgrow this pot, and your keeper will choose a bigger one for you over a new phone case.

## How it works

`main.py` writes that single line to `/output/entry.txt` — one line,
at most 120 characters, UTF-8. Run it with:

```sh
python3 main.py
```
